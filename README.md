# Customer Behavior Analysis Dashboard

## Project Overview

This project analyzes customer shopping behavior using Python, PostgreSQL, SQL, and Power BI. The dashboard provides insights into customer purchasing patterns, revenue trends, subscription analysis, and sales performance.

---

## Technologies Used

* Python
* Pandas
* PostgreSQL
* SQLAlchemy
* SQL
* Power BI

---

## Features

* Data cleaning and preprocessing using Python
* Feature engineering for age groups and purchase frequency
* PostgreSQL database integration
* SQL-based business analysis
* Interactive Power BI dashboard
* Revenue and sales analysis by category and age group
* Subscription behavior insights

---

## Dataset Information

The dataset contains:

* Customer demographics
* Product categories
* Purchase amount
* Review ratings
* Subscription status
* Shipping details
* Payment methods
* Purchase frequency

---

## Dashboard Insights

* Total Customers: 3.9K
* Average Purchase Amount: $59.76
* Average Review Rating: 3.75
* Clothing category generated highest revenue
* Young Adults contributed highest sales
* 73% customers are non-subscribers

---

## Business Recommendations

* Improve subscription programs
* Focus marketing on clothing products
* Target young adult customers
* Improve customer engagement and loyalty
